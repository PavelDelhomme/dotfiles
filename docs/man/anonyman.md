# anonyman(1) — anonymisation Tor / I2P / proxies

## Nom

**anonyman** (alias **anonymman**) — gestion labo de Tor, I2P et listes de proxies publics.

## Synopsis

```text
anonyman [help | -h | --help | aide]
anonyman status | check | doctor
anonyman tor [status|start|stop]
anonyman i2p [status|enable|disable|ports]
anonyman proxy [refresh|list|count]
anonyman run -- <commande>
```

## Description

Centralise ce qui était dispersé dans `cyberman anon` / scripts Tor.  
Les proxies gratuits sont **non fiables** — usage laboratoire uniquement.

## Voir aussi

`installman tor` · `installman i2p` · `configman i2p` · `netman tor` · `netman i2p` · `cyberman anon`
